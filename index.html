📝 Method 1: Simple Text Format

✨ Super Easy! Just type each question and answer. The system will auto-format everything!
Rules:
• Q: at start = Question
• A: at start = Answer
• Empty line = new paragraph
• Line starting with - or * = bullet point
• Line starting with 1. 2. = numbered list
• **text** = bold
• --- on its own line = separator between questions

📋 Method 2: Bulk Paste (One Question Per Line)

✨ Fastest method! Just paste questions (one per line), then write answers below.
Format: Each line is one question. Then type answers in the same order.

📊 Method 3: CSV / Excel File

✨ Best for many questions!
1. Click 📥 Download Template to get a CSV file
2. Open in Excel / Google Sheets / Notepad
3. Fill in your questions and answers
4. Save as CSV and upload below
